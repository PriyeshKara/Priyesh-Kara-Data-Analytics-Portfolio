# Power BI report notes

## Model objects observed

- `CovidDataFull`
- `Covid Vaccinations`
- Measure: `VaccinationRate`

## Visual design

The report uses two KPI cards and a map. The Philippines is highlighted in the case and vaccination-coverage cards, while the map provides a global comparison view.

## Portfolio explanation

This project demonstrates the transition from a data model to a concise dashboard: select a meaningful measure, provide geographic context and use KPI cards to make a selected country easy to interpret.
