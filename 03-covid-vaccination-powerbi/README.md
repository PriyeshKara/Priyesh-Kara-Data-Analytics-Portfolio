# Global COVID-19 Vaccination Analysis Dashboard — Power BI

## Overview

A Power BI report combining COVID-19 case and vaccination data to communicate country-level patterns and vaccination coverage.

## Report contents

The report contains one page with three visuals:

- **Total Cases as of 2026** — KPI card filtered to the Philippines
- **Global Vaccination Trends** — map using country location and vaccination-related fields
- **Vaccination Coverage** — KPI card using the `VaccinationRate` model measure

## Skills demonstrated

- Power BI report layout
- Data model relationships between case and vaccination tables
- KPI card design
- Geographic visualisation
- DAX measure usage
- Formatting and communication of public-health indicators

## Recommended improvements

For a stronger public portfolio version, add a data-source note, refresh/extraction date, a time-series visual, country/date slicers and a written interpretation of the main findings. The PBIX should be accompanied by exported screenshots because GitHub cannot preview the report interactively.
