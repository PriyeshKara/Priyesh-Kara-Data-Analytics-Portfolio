# Case study: Gurudwara Donation Automation System

## Challenge

A community organisation needed a more consistent way to capture donation information and maintain usable records while reducing reliance on paper administration.

## Approach

I designed a structured workbook workflow around three components: a donor reference list, a donation input form and a central donation-history table. The design separates input from history and uses standard fields so the data can be reviewed, filtered or analysed later.

## Outcome

The broader process reduced paper usage by 40% and improved data-capture efficiency. The project shows how a practical data-quality intervention can improve an operational process without requiring a complex enterprise system.

## What I would add next

1. Document the custom scripting layer and its trigger or run process.
2. Add a dashboard showing monthly donation totals and payment-method mix.
3. Add an audit log for amendments and corrections.
4. Add role-based access and retention rules.
5. Keep all public demonstrations fictional and separated from live records.
