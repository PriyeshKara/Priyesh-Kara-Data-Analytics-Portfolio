# Gurudwara Donation Automation System

## Overview

A real-world community administration project focused on improving donation data capture, reducing paper-based administration and creating a more consistent record-keeping process.

The public demonstration workbook is a **sanitised copy**. It contains fictional donor names, addresses, postcodes, receipt references and notes. No real donor information should be published in a public repository.

## Business problem

The donation process required reliable capture of donation details, donor information, payment type and taxpayer status. Manual or fragmented capture creates avoidable rework, inconsistent records and difficulty producing reliable reports.

## Solution demonstrated

- A donor reference list for repeat data entry
- A structured donation-input form
- A central donation-history sheet
- Standardised fields for date, amount, payment type, taxpayer status and receipt reference
- Data validation rules to support consistent entry
- A workflow that can be extended with custom scripting or further automation

## Result

The wider community process reduced paper usage by **40%** and improved data-capture efficiency. The workbook demonstrates the data structure and operational workflow; the separate script or automation layer should be added when available.
