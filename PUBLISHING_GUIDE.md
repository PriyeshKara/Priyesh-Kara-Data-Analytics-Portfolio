# Publishing guide

## Before uploading to GitHub

- Do not upload the original Gurudwara workbook; use only the sanitised copy.
- Confirm that no donor, address, postcode, receipt reference or note is present in screenshots.
- Add the custom script only after removing credentials, API keys and private paths.
- Add PBIX screenshots because GitHub does not render the report interactively.
- Consider adding a licence or a note that the portfolio is for demonstration.
